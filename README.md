# Thai Chameleon TTS — GitHub Pages

Static HTML demo with browser-based speech synthesis (Web Speech API). Free hosting and no paid API key. **This version uses voices available in the user's browser/device, not server-hosted AI voices.** Voice quality varies; MP3 export and a guaranteed Jenny voice are not included.

## Deploy
1. Extract the ZIP file.
2. Open `https://github.com/vocabularychallenge/thaichameleon-tts`.
3. Upload **the files inside `site/`**, especially `index.html`, into the repository root (not a `site` folder).
4. Commit changes.
5. GitHub repository Settings > Pages > Deploy from a branch > `main` > `/ (root)` > Save.
6. Default URL: `https://vocabularychallenge.github.io/thaichameleon-tts/` (after Pages deployment succeeds).

## Custom domain later
Set the Pages custom domain to `tts.thaichameleonbook.com` and configure the appropriate DNS CNAME at Porkbun. Do not change DNS for the main domain.
